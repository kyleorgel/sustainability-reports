Data & API

Everything on the Report Index is free to reuse. No key, no sign-up.

How current is it?

Every entry on the index is rechecked twice a week by automated readers that watch each company's own disclosure page, and new reports are confirmed by hand before they are published. Any change to the index reaches every address below within an hour. /api/v1/meta and meta.json carry the time of the last update.

Which companies are included?

Every company in the S&P 500, plus every company that has left the S&P 500 since the index began. A company is added when it joins and is never removed when it drops out, so the index lists more than 500 companies. Former members keep being checked like every other entry. The data does not mark which companies are current members.

JSONreports.orgel.us/api/v1/reports

Every company, filterable by sector, year, ticker, status or a search term.

GET /api/v1/reports

Returns the companies that match your filters. With no parameters it returns the whole index.

ParameterExampleMeaning
sector?sector=EnergyExact sector name (case-insensitive). The eleven GICS sectors: Communication Services, Consumer Discretionary, Consumer Staples, Energy, Financials, Health Care, Industrials, Information Technology, Materials, Real Estate, Utilities.
year?year=2026Report year equals this value. year_min and year_max give a range.
ticker?ticker=AAPL,MSFT,NVDAOne or more tickers, comma-separated (up to 50).
status?status=noneactive = a report or disclosure page link is published; none = the company has not published one.
q?q=waterSubstring search over company, ticker, sector and report name (up to 80 characters).
format?format=csvjson (default) or csv. Add &download=1 to receive the CSV as a file download.

Filters combine with AND: /api/v1/reports?sector=Utilities&year_min=2025&format=csv.

    "total": 514,
    "count": 21,
    "filters": { "sector": "Energy" }
  },

    {
      "company": "APA Corporation",

      "reportUrl": "https://...",

reportUrl and landingPageUrl are null when a company has not published one. reportYear is a number, or null. All fields are UTF-8 strings otherwise.

GET /api/v1/meta

Last update time, the number of companies, how many have a published report, and the list of endpoints. Useful for a "last updated" label or to decide whether to re-download.

Python

import requests
r = requests.get("https://reports.orgel.us/api/v1/reports", params={"sector": "Energy"})
for row in r.json()["reports"]:
    print(row["company"], row["reportYear"], row["reportUrl"])

# or straight into pandas
import pandas as pd
df = pd.read_csv("https://reports.orgel.us/api/v1/reports?format=csv")

JavaScript

const res = await fetch("https://reports.orgel.us/api/v1/reports?year_min=2026");
const { meta, reports } = await res.json();
console.log(meta.count, "reports from", meta.updatedAt);

Command line

curl -s "https://reports.orgel.us/api/v1/reports?ticker=AAPL,MSFT" | jq '.reports[] | {company, reportYear, reportUrl}'
CSVreports.orgel.us/api/v1/reports?format=csv

The same data as a spreadsheet file. Works with Google Sheets, Excel, R and pandas.

What you get

The same endpoint as the JSON, so every filter listed under JSON works here too (sector, year, ticker, status, q). Columns, in order: Company, Ticker, Sector, Report Name, Report Year, Status, Report URL, Landing Page URL. The file is UTF-8 with a byte-order mark so Excel opens it correctly. Add &download=1 to receive it as a file download instead of in the browser.

Google Sheets

=IMPORTDATA("https://reports.orgel.us/api/v1/reports?format=csv")

Add filters to the URL to import a slice, for example ?sector=Financials&format=csv. Google refreshes imported data about once an hour.

Excel

Data → Get Data → From Web, paste https://reports.orgel.us/api/v1/reports?format=csv, then Load. Refresh any time with Data → Refresh All. Or use the Download button on the index page for a formatted workbook of whatever is on screen.

R and pandas

df <- read.csv("https://reports.orgel.us/api/v1/reports?format=csv")      # R
df = pd.read_csv("https://reports.orgel.us/api/v1/reports?format=csv")     # pandas
Feedreports.orgel.us/feed.xml

Atom feed: one entry each time a company's latest report changes. Add it to any feed reader or automation tool.

How it works

feed.xml is an Atom feed with one entry each time a company's latest report moves to a newer year on the index - roughly a handful a week during reporting season. Each entry links to the report itself and names the previous year it replaced. Subscribe in a feed reader (Feedly, Inoreader, NetNewsWire, Outlook), or point a tool such as Zapier, Make, n8n or IFTTT at it to get an email or a Slack message when a report you follow is published.

The same events are available as JSON at changes.json (newest first, up to 1,000 kept), which is easier to process in code than the feed.

Raw filereports.orgel.us/data.json

The exact file the index page renders from. Best for bulk or scheduled downloads.

Format

An array of records, one per company, each wrapped in a fields object that uses the index's own column names: Company Name, Ticker, Sector / Industry, Report Name, Report Year, Report URL, Landing Page URL. Values are strings; a company with no report has an empty or None Published value. About 220 KB, cached for five minutes, cross-origin allowed.

[
  { "fields": { "Company Name": "3M", "Ticker": "MMM", "Sector / Industry": "Industrials",
                "Report Name": "2026 Global Impact Report", "Report Year": "2026",
                "Report URL": "https://...", "Landing Page URL": "https://..." } },
  ...
]

Use this for nightly mirrors or one-off bulk analysis instead of calling the API repeatedly. meta.json carries the last update time, so you can skip the download when nothing has changed.

Limits and fair use

  • Responses are cached for five minutes, so polling more often than that returns the same data. Once an hour is plenty.
  • For bulk or scheduled downloads, fetch data.json (about 220 KB) rather than calling the API repeatedly.
  • Cross-origin requests are allowed from any website (Access-Control-Allow-Origin: *).
  • This is a free service run by one person. There is no uptime guarantee, and abusive traffic will be blocked.

Terms and attribution

The index itself - company, ticker, sector, report name, year and the links - is free for any use, commercial or not. A credit such as "Source: ORGEL Sustainability Report Index, reports.orgel.us" is appreciated. The reports the links point to belong to the companies that published them and stay on those companies' own websites; this index does not host or redistribute them. The data is offered as-is: it is checked carefully, but you should verify anything you rely on against the company's document.
